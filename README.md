Je m'appelle Laurent, j'ai 17 ans et je suis étudiant en première année de licence professionnelle MIAW à l'Université de Limoges. Cette formation que j'effectue à distance me permet d'améliorer mes compétences en programmation et en design dans le but de devenir développeur web.

Je réalise aussi un certain nombre de projets informatiques personnels, principalement en utilisant les technologies web (HTML, CSS, JavaScript), Python et Rust.

## Projets web
J'ai créé un certain nombre de sites web et d'applications web :
- [le site du catéchisme et de l'aumônerie d'Embrun](https://github.com/lfavole/sitekt)
- [un tableau de scores très rapide pour suivre Roland-Garros en direct](https://github.com/lfavole/rolandgarros-scores), que je prends plaisir à utiliser chaque année
- [un outil pour interagir efficacement](https://github.com/lfavole/digipad-api) avec [Digipad](https://digipad.app), notamment pour créer et modifier un nombre important de pads très rapidement
- [un site web contenant mes flashcards Anki, mis à jour automatiquement](https://github.com/lfavole/flashcards) ([Quoi ? Vous ne connaissez pas les flashcards ?](https://apps.ankiweb.net))
- [un système de vote sécurisé et anonyme, basé sur des signatures aveugles](https://github.com/lfavole/voting)
- [une page de nouvel onglet personnalisée](https://github.com/lfavole/newtab) disponible en tant qu'[extension Firefox](https://addons.mozilla.org/fr/firefox/addon/lfnewtab/)
- [un dépôt centralisant mes données ouvertes](https://github.com/lfavole/opendata) (relevés de températures, citations...) avec une interface pour les visualiser
- [un portfolio simple en HTML/CSS](https://github.com/lfavole/portfolio)
